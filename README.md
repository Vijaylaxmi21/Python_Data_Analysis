## 📌 About The Project

Python_Data_Analysis is a hands-on project focused on loading, cleaning, structuring, and analysing Amazon store data stored in JSON format.

The project aims to transform raw data into meaningful insights and implement a basic rule-based product recommendation feature.

## ✨ Features

- 📂 **JSON Data Loading** – Loading raw data from a JSON file.
- 🧹 **Data Cleaning** – Cleaning and organizing the dataset.
- 🗂️ **Data Structuring** – Preparing data for analysis.
- 📊 **Insight Generation** – Extracting meaningful information.
- ⭐ **Rating Analysis** – Calculating average ratings and poor rating percentages.
- 💡 **Recommendation Feature** – Generating recommendations using rule-based logic.

## 💡 Recommendation System

A basic rule-based recommendation feature was implemented using product ratings.

| Rating Condition | Recommendation |
|:---|:---|
| Rating ≥ 4 | 🍎 Apple |
| Rating < 4 | 📱 Samsung |
